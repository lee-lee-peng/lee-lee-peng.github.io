    Kate编辑器如何格式化markdown文件

    背景

    由于Kate自带的format插件不支持markdown，而format插件又不能通过配置的方式加入markdown支持，因此，需通过“外部工具”的方式实现需求

    所需工具

    Prettier，需用npm安装

    npm install -g prettier

    配置方法

    "工具"->"外部工具"->"配置"，新增一个外部工具，分类可自行定义，个人是将它放在“格式化”分类中

    • 名称：格式化Markdown
    • 可执行文件：prettier或其完整路径
    • 使用文件路径方式避免中文乱码参数：--write %{Document:FilePath}
    • 输入：留空即可
    • 工作目录：留空即可
    • MIME类型：text/markdown
    • 保存：无
    • 保存时自动格式化触发器：保存后
    • 重要钩选“执行后重新加载当前文档”
    • 输出：忽略
    • 编辑器命令：留空即可

    Lutris玩proton runtime游戏的一些设置

    问题：启动就退出，code 256

    原因：proton runtime依赖steam runtime，可通过设置STEAM_COMPAT_CLIENT_INSTALL_PATH这个环境变量解决

    一般情况下，只要安装了steam，都可通过使用下列命令（启动lutris前，可写入.bashrc/.zshrc/.profile/.zprofile等文件永久生效）

    STEAM_COMPAT_CLIENT_INSTALL_PATH=~/.local/share/Steam

    实测，在lutris的游戏里设置该环境变量无效

    问题：在同一个WINEPREFIX下启动的Cheat Engine读取不到内存

    原因：需要额外的环境变量，将cheatengine.exe的完整路径设置为PROTON_REMOTE_DEBUG_CMD，此环境变量可以通过lutris的GUI中设置

    PROTON_REMOTE_DEBUG_CMD="/home/myusername/.steam/steam/steamapps/Cheat_Engine_7.5/cheatengine.exe"

    设置好后，启动游戏时会自动启动Cheat Engine，如果Cheat Engine退出了，需要重新启动游戏，参考：https://wiki.cheatengine.org/index.php?title=Help\_File:Using\_Cheat\_Engine\_on\_Linux\_with\_Proton
